# Power BI Executive Dashboard Integration Guide

This guide details how to build and maintain the Power BI executive reporting artifact (`dashboard/churn_dashboard.pbix`) using calibrated, holdout-scored retention data generated by the platform.

---

## 1. Data Source Ingestion & Pipeline Integration

Before opening Power BI, ensure the latest pipeline export has been executed:
```bash
python main.py --step powerbi
```

### Files to Import (Get Data -> Text/CSV):
1. **Primary Analytical Dataset:** `reports/powerbi/powerbi_dataset.csv`
   - *Table Name in Power BI:* `Customers`
   - *Row Count:* 10,000 customers.
   - *Evaluation Split Column:* `ModelDataset` (`Train (OOF)` vs `Test`).
   - *Calibration Column:* `CalibratedProbability` (honest Platt-scaled probability).
   - *Segmentation Column:* `SegmentName` (rule-named K-Means cluster).
2. **Model Evaluation Benchmark:** `reports/model_comparison.csv`
   - *Table Name in Power BI:* `ModelBenchmarks`
   - *Metrics:* Accuracy, Precision, Recall, F1 Score, ROC-AUC, PR-AUC, Brier Score.
3. **High-Risk Export (Optional):** `reports/powerbi/high_risk_customers.csv`
   - Filtered customer table where `RiskSegment = "High"`.

## 3. Essential DAX Measures

Create a dedicated measures table `_Measures` and insert the following formulas:

```DAX
// 1. Portfolio Demographics
Total Customers = COUNTROWS(Customers)
Churned Customers = CALCULATE([Total Customers], Customers[Exited] = 1)
Retained Customers = CALCULATE([Total Customers], Customers[Exited] = 0)
Empirical Churn Rate % = DIVIDE([Churned Customers], [Total Customers], 0)

// 2. Calibrated Probability & Risk Distribution
Avg Calibrated Probability = AVERAGE(Customers[CalibratedProbability])
High Risk Customers = CALCULATE([Total Customers], Customers[RiskSegment] = "High")
High Risk Share % = DIVIDE([High Risk Customers], [Total Customers], 0)
Balance At Risk = CALCULATE(SUM(Customers[Balance]), Customers[RiskSegment] = "High")
Total Portfolio Balance = SUM(Customers[Balance])
Balance At Risk Share % = DIVIDE([Balance At Risk], [Total PortfolioBalance], 0)

// 3. Operational Signals
Avg Digital Usage Score = AVERAGE(Customers[DigitalUsageScore])
Avg Transaction Count = AVERAGE(Customers[TransactionCount])
Complaint Incidence Rate % = DIVIDE(CALCULATE([Total Customers], Customers[CustomerComplaints] > 0), [Total Customers], 0)
Loan Default Churn % = CALCULATE([Empirical Churn Rate %], Customers[LoanStatus] = "Defaulted")

// 4. Honest Holdout Evaluation (Test-Set Filtered)
Test Set ROC-AUC = 0.7295
Test Set Brier Score = 0.1216
Theoretical AUC Ceiling = 0.7480
```

## 4. Multi-Page Report Layout & Visual Specifications

| Page | Primary Purpose | Key Visual Elements |
|---|---|---|
| **1. Executive Summary** | High-level portfolio risk and capital at risk. | KPI Cards: `Total Customers`, `Empirical Churn Rate %`, `Balance At Risk`, `High Risk Customers`.<br/>Donut Chart: `RiskSegment` distribution.<br/>Area Chart: Churn by `Tenure`.<br/>Global Slicer: `ModelDataset` (use `Test` for holdout reporting). |
| **2. Customer Demographics** | Attrition by segment, geography, and gender. | Clustered Column: `Empirical Churn Rate %` by `Geography` and `Gender`.<br/>Bar Chart: Customers by `AgeBand`.<br/>Matrix: `AgeBand` x `Geography` heatmap with conditional formatting. |
| **3. Behavioral Intelligence** | Activity, transactions, and digital adoption. | Scatter Plot: `TransactionCount` vs `Balance` colored by `RiskSegment`.<br/>Line Chart: `Avg Digital Usage Score` across `Tenure`.<br/>Bar Chart: Complaint incidence vs churn rate. |
| **4. Segmentation Overview** | Behavioral K-Means cluster profiling. | Horizontal Bar: Customer volume per `SegmentName`.<br/>Scatter Plot: `Avg Balance` vs `Avg Calibrated Probability` by segment.<br/>Table: Segment profile summaries. |
| **5. High-Risk Action Roster** | Operational customer list for outreach. | Table: `CustomerId`, `SegmentName`, `Geography`, `Age`, `Balance`, `CalibratedProbability`.<br/>Conditional data bars on `CalibratedProbability`.<br/>Filtered to `RiskSegment = "High"`. |
| **6. Model Governance** | Algorithmic audit and calibration transparency. | Table from `ModelBenchmarks` comparing algorithms.<br/>Image Visuals: Embed `reports/roc_curve.png` and `reports/confusion_matrix.png`.<br/>Callout card highlighting honest Platt calibration. |

## 5. Synchronization & Global Filters

- Configure a synchronized slicer pane across all pages containing:
  - `ModelDataset` (defaults to `Test` for verified holdout reporting).
  - `Geography` (`France`, `Germany`, `Spain`).
  - `Gender` (`Female`, `Male`).
  - `RiskSegment` (`Low`, `Medium`, `High`).
- Save the completed report as `dashboard/churn_dashboard.pbix`.
